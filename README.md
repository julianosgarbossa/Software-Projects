## 🍎 Desenvolvimento iOS

### BF-NFT

Aplicativo iOS que simula um marketplace de NFTs, permitindo explorar obras digitais, pesquisar criadores, filtrar itens por categoria, acompanhar ofertas e consultar uma carteira com saldo em Ethereum e histórico de transações.

**Tecnologias:** Swift • UIKit • View Code • MVVM • Firebase • Alamofire

[🔗 Ver Repositório no GitHub](https://github.com/julianosgarbossa/BF-NFT)

### SocialNetwork

Aplicativo iOS de rede social com cadastro e autenticação de usuários, visualização de stories e publicações, interação por curtidas e carregamento remoto de dados.

**Tecnologias:** Swift • UIKit • View Code • MVVM • Firebase • URLSession

[🔗 Ver Repositório no GitHub](https://github.com/julianosgarbossa/SocialNetwork)
